:........................................................................
: *** MCP: Exposing database entities as AI tools ***

: DAB 2.x also exposes configured entities through Model Context Protocol (MCP)
: MCP is enabled by default in the V2 config:
:
:   "mcp": {
:     "enabled": true,
:     "path": "/mcp"
:   }
:
: This means the same Book, Author, BookDetail, and stored procedure entities
: are now available to MCP-compatible AI clients as tools.

: MCP is not browsed directly like REST or GraphQL.
: Use MCP Inspector as the MCP client.

: In a second command prompt:

npx -y @modelcontextprotocol/inspector

: In MCP Inspector:
:   Transport Type: Streamable HTTP
:   URL: http://localhost:5000/mcp
:   Click Connect
:   List tools
:   Call read_records for Book
:   Call execute_entity for GetBooksCowrittenByAuthor
:
: Show available tools:
:   describe_entities
:   read_records
:   create_record
:   update_record
:   delete_record
:   execute_entity
:   aggregate_records
:
: Explain:
:   REST is for HTTP clients
:   GraphQL is for structured query clients
:   MCP is for AI agents

: Run MCP demos:
:
: 1. Describe available entities
:   Tool: describe_entities
:   Expected: Book, Author, BookDetail, GetBooksCowrittenByAuthor
:
: 2. Read records from Book
:   Tool: read_records
:   Entity: Book
:   Expected: Returns books without writing SQL
:
: 3. Aggregate books
:   Tool: aggregate_records
:   Entity: Book
:   Example: count books, group by Year
:
: 4. Execute stored procedure
:   Tool: execute_entity
:   Entity: GetBooksCowrittenByAuthor
:   Parameters:
:       SearchType = C
:       Author = Asimov
:
: Key point:
:   No new database code was written.
:   No MCP tools were manually coded.
:   DAB generated REST, GraphQL, and MCP surfaces from the same config.
